highlights:
  - title: File Data Replacement
    description: added replacing file data feature, which allows to upload new content to the existing file (overriding the current data), keeping the File ID and its path unchanged
  - title: Monitoring & Transfer Insights
    description: added Quality of Service statistics to transfers charts for better visibility into data movement and service levels
  - title: Identity & User Provisioning Expansion
    description: extended user creation APIs with linked accounts support, enabling pre-creation of IdP users before first login using OIDC attributes
  - title: Performance & Request Handling Improvements
    description: introduced a more resilient GraphSync process pool to prevent single-client flooding and optimized shares/public data performance in smaller spaces
  - title: Custom Sidebar Styling
    description: added experimental support for customizing style of the sidebar using static files without rebuilding the software
  - title: Public Data & Europeana Metadata Updates
    description: expanded metadata editing with new material types and collapsible EDM categories, added an option to ignore validation errors, and aligned Europeana URLs with required standards
  - title: Stability & Compatibility Fixes
    description: resolved issues across HTTP storage support, custom frontpage login test mode, long membership path display and new aws-cli PUT request handling in OneS3
  - title: Web GUI Usability Enhancements
    description: improved everyday workflows with smarter rename behavior, remembered share navigation state, better paging, clearer conflict labels and fixes for download dialogs
